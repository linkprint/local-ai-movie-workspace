## Command Ledger

```text
UP -> DOWN -> LEFT -> RIGHT -> LEFT -> RIGHT -> UP -> DOWN -> LEFT -> RIGHT
Ending emphasis: LEFT -> RIGHT -> UP -> hold.
```

Every foreground finger cue and full-body response starts on the same beat. LEFT and RIGHT move the dancer's center of mass and both feet; they never collapse into a hip twitch.
