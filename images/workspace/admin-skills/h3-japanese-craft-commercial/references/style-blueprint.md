# Style Blueprint

## Viral Evidence

The 495-vote Reddit post [Short japanese knife commercial (MiniMaxH3 + After Effects)](https://www.reddit.com/r/StableDiffusion/comments/1vh5m36/short_japanese_knife_commercial_minimaxh3_after/) used H3 for video/audio and style frames for consistency, then edited 11 generated clips from five prompts. The creator recommends a style frame for each clip and notes that H3 can prompt camera cuts. This skill compresses the tactile language into one original short commercial and reserves exact lettering for post.

## Reliable 10-Second Structure

- 0–35%: material/process macro.
- 35–70%: one precise functional proof.
- 70–100%: clean hero still-life with simplified motion.
- Use side light and foley as the rhythm; no more than two motivated cuts.
