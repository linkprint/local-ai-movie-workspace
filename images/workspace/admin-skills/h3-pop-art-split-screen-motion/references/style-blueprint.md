## Adaptable Panel Arc

- 0–20%: single full-frame hero object and governing color key.
- 20–45%: vertical two-panel split with complementary detail and three-quarter views.
- 45–70%: three-panel or diagonal layout with one repeated motion phase across panels.
- 70–85%: gutters sweep away; color and texture compress toward center.
- 85–100%: recombined hero lockup with the exact original construction.
