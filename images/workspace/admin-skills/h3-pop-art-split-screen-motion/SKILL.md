# H3 Pop Art Split Screen Motion

Use a dense living panel grid as the motion system while keeping every product silhouette, colorway, detail crop, and authorized brand element stable.

## Route the Request

- For prompt writing or refinement, return text only.
- Read [references/style-blueprint.md](references/style-blueprint.md) and use $h3-prompt-writing.
- Invoke $h3-video-generation only when the user explicitly asks to render.
- A product reference plus separate style references requires native Ref2VA. Put the product first, add style references in deterministic order, and bind every `<Picture N>` to product or graphic-treatment authority.
- For the selected five-image impasto sneaker campaign, use the exact reference-role map and 15-second act structure in the reference file. Do not collapse the five images into one generic style reference.

## Build the Motion System

1. Assign each reference one independent role: hero silhouette/style, walking ensemble, alternate profile colorway, worn ankle detail, or glossy macro material detail. Ignore every unassigned property.
2. Lock product construction, stripe or panel placement, sole, laces, colorway, crop, and painterly treatment before designing movement.
3. For the selected recipe, use one coherent gouache/acrylic impasto system: flat saturated cobalt, marigold, coral, and cream fields; visible dry brush texture; thick painted outlines; no photorealism, gradients, or CGI sheen.
4. Favor two-up and three-up simultaneous panels. Every product crop must snap, rotate, stride, flash, or reconfigure; no static full-frame hold longer than one second except the final lockup.
5. Follow the act density from the reference file: flash grid, panel slam, freeze-stutter, razor slice, two-up swaps, radial panel spin, frame-in-frame, three-panel montage, final single-color lockup.
6. Keep every panel's view compatible with its assigned reference. Never replace the hero with the alternate shell-toe silhouette or invent an extra colorway.
7. Synchronize every split, slam, spin, swap, and freeze to an original retro-funk commercial cue plus restrained whooshes and impacts.
8. If an exact brand wordmark or logo is requested, use it only when the user supplied or authorized that asset. Show it once in the final lockup, perfectly stable and separate from the product. Otherwise use an original unbranded lockup.

## Render Rules

- Use 15 seconds for the selected five-reference campaign. The modal style demo remains a condensed 10-second unbranded T2VA preview at 864x480.
- Explicit 768p means 1344x768 and may never be downgraded.
- Exclude adult content, nudity, sexualized framing, unauthorized trademarks, unauthorized named IP, celebrity likeness, product/colorway drift, mixed reference roles, garbled text, extra logos, subtitles, and watermarks.

## Output

Return mode, five-image role map when applicable, product lock, panel timeline, duration/resolution, exact approved text/logo policy, complete H3 prompt, and Broker limitations. For a real render, verify reference-role separation, product continuity, panel density, beat synchronization, and the final lockup before returning the absolute Portal URL.
