# Anime Character Showcase Template

## Source and Technique

This blueprint was selected from Kiki's X post [“MiniMax H3 is surprisingly good at anime PVs”](https://x.com/Mayz1169/status/2087870514400502028), which showed about 25.7K views, 401 likes, and 317 bookmarks when reviewed. The author supplied a full prompt built around an environment reference, a hero character sheet, a graphic-novel 360-degree turnaround, staged environment assembly, title choreography, and a seamless loop.

Use the structure, not the source character, carnival design, titles, or campaign identity.

## Full Ref2VA Template

Replace every bracketed value. Preserve any user-provided exact title text verbatim.

Exclude soft gradients, painterly blur, realistic rendering, cinematic fog, soft fades, slow dissolves, organic morphing, and slow camera movement.

At the exact end, complete the full rotation and return to the opening composition: identical character angle, pose, scale, framing, environment arrangement, title-free state, and lighting. The first and final frames must visually match with no freeze, jump cut, or visible reset.

non_diegetic_music: An original seamless-loop [MUSIC STYLE] cue using [INSTRUMENTS AND RHYTHM]. Match the first and final downbeats exactly. Do not reference an existing song.

The character completes one smooth continuous 360-degree rotation while the camera, lens, horizon, and framing remain perfectly static; the character rotates, not the camera.
