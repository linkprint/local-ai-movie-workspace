# H3 Ancient Title Sequence

Translate a fictional dynasty, conflict, and emblem into one coherent material-and-symbol title journey.

## Route the Request

- For prompt writing or refinement, return text only.
- Read [references/style-blueprint.md](references/style-blueprint.md) and use $h3-prompt-writing.
- Invoke $h3-video-generation only when the user explicitly asks to render.
- Use T2VA by default. Use I2VA only when one opening artwork is also the exact first frame. Use native Ref2VA for multiple independent artwork or motion references.

## Design the Sequence

1. Define a fictional period premise, one governing color pair, and three recurring materials such as mineral ink, oxidized bronze, woven silk, lacquer, or stone.
2. Build four symbolic images that transform by shared shape or material: artifact to map, map to landscape, landscape to emblem, emblem to title.
3. Keep every transition physically motivated by ink spread, fabric pull, dust, reflection, flame, rain, or carved relief.
4. Reserve clear negative space for one exact title and an optional subtitle. Hold the final title for at least one second.
5. Use culturally coherent but fictional heraldry and writing surfaces. Do not fabricate documentary claims.
6. Score with original restrained percussion, plucked strings, breath, wood, or metal; avoid named songs.

## Render Rules

- Use 10–15 seconds; default demo is 10 seconds at 864x480.
- Explicit 768p means 1344x768 and may never be downgraded.
- Exclude adult content, nudity, sexualized framing, graphic gore, modern objects, named franchises, celebrity likeness, incoherent scripts, extra readable text, logos, subtitles, and watermarks.

## Output

Return the title block, symbolic beat sheet, mode, duration/resolution, complete H3 prompt, and material continuity locks. For a real render, verify period coherence, transformations, and final title hold before returning the absolute Portal URL.
