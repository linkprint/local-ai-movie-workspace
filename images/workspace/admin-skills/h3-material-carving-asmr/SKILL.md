# H3 Material Carving ASMR

Make every cut accumulate into one continuous sculpture while preserving material physics, tool safety, and hand continuity.

## Route the Request

- For prompt writing or refinement, return text only.
- Read [references/style-blueprint.md](references/style-blueprint.md) and use $h3-prompt-writing.
- Invoke $h3-video-generation only when the user explicitly asks to render.
- Use T2VA by default or I2VA for one authorized starting object. For separate design references, use native Ref2VA and list them in prompt order under `reference_images`.

## Carve the Reveal

1. Specify one non-living material and its exact surface, density, moisture, grain, crumb, curl, or dust behavior.
2. Design an original non-infringing sculpture with a simple silhouette and three progressive detail stages.
3. Keep one tool, two adult hands, workbench, lighting, object orientation, and camera side stable.
4. Show coarse blocking, mid-form refinement, then fine texture. Removed material stays removed; cuts never heal or move.
5. Keep blades moving away from fingers and never depict injury, skin contact, blood, flesh, or pain.
6. Use close, dry, material-specific foley. Avoid music unless the user requests it.
7. End on a clean turn or brush-off reveal without magically swapping the sculpture.

## Render Rules

- Use 8–15 seconds; default demo is 10 seconds at 864x480.
- Explicit 768p means 1344x768 and may never be downgraded.
- Exclude adult content, nudity, sexualized framing, minors, injury, gore, body horror, living-subject cutting, named anime or game characters, celebrity likeness, unsafe tool use, extra hands, logos, subtitles, and watermarks.

## Output

Return mode, material sheet, carving stages, duration/resolution, complete H3 prompt, safety locks, and any Broker limitation. For a real render, verify progressive geometry and safe hands before returning the absolute Portal URL.
